# Task: Organize Creative Studio Modules

Optimize the "Studio" menu group by separating execution history from the final product assets.

## User Requirements
- Rename "Thư viện thành phẩm" (Asset Library) to "Lịch sử sáng tạo" (Creation History) to reflect its role as a run log.
- Create a new module called "ASSETS" specifically for products generated by the tools.
- "ASSETS" must be independent of Knowledge Base files/assets.
- Place "ASSETS" inside the "Xưởng sáng tạo" (Studio) menu group.

## Proposed Architecture

### 1. i18n Updates
- `navigation.creationHistory`: "Lịch sử sáng tạo" / "Creation History"
- `navigation.assets`: "ASSETS" / "ASSETS"
- `navigation.creationTools`: "Công cụ sáng tạo" / "Creation Tools"

### 2. Sidebar Navigation
- Group: **Studio** (`Xưởng sáng tạo`)
  1. **Creation Tools** (`Công cụ sáng tạo`) -> `/creation-tools`
  2. **ASSETS** -> `/assets`
  3. **Creation History** (`Lịch sử sáng tạo`) -> `/my-products`

### 3. Frontend Implementation
- New Page: `/app/(dashboard)/assets/page.tsx`
- New Component: `AssetsGallery` to display images/videos generated by tools.
