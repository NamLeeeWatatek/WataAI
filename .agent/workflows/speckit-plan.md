---
description: Starts the technical implementation planning phase using Speckit.
---

1.  **Run Tool**: Execute the Speckit plan setup script.
    -   Command: `& .\.specify\scripts\powershell\setup-plan.ps1`
2.  **Read Output**: Capture the `IMPL_PLAN` path from the command output.
3.  **Read Spec**: Read the corresponding `spec.md` file to understand requirements.
4.  **Edit Plan**:
    -   View the newly created plan file.
    -   Fill in the "Proposed Architecture", "Tech Stack", and "Data Model" sections.
    -   Ensure the plan aligns with the `spec.md`.
5.  **Review**: Ask the user to review the technical plan.
