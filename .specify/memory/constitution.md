# Project Constitution

## Core Principles

1. **Code Quality**: Maintain high standards with strict TypeScript typing, ESLint compliance, and clean architecture.
2. **Testing**: Implement comprehensive testing (Unit, Integration, E2E) for all critical paths.
3. **User Experience**: Prioritize intuitive, responsive, and accessible (WCAG 2.1 AA) designs.
4. **Performance**: Optimize for speed and efficiency, monitoring Core Web Vitals.
5. **Consistency**: Adhere to the defined design system and codebase conventions (e.g., specific folder structures, naming patterns).

## Governance

- **Decision Making**: Technical decisions should be documented in ADRs (Architecture Decision Records) when significant.
- **Review Process**: All code changes require validation against the spec and passing build/lint checks.
- **Spec-Driven**: All new features and major refactors must start with a Specification phase before Implementation.
